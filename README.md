# Vitrine Alegre - E-Commerce em React

Links do Projeto:
- Repositório GitHub: https://github.com/zRafs/ecommerce2
- Site Publicado (Vercel): ecommerce2-rafa-9c73.vercel.app

## Sobre o Projeto
O Vitrine Alegre é uma aplicação de e-commerce desenvolvida em React + Vite para a disciplina de Desenvolvimento Front-End II (IFES Campus de Alegre - TADS).

A aplicação consome a API pública DummyJSON, convertendo os preços em Dólar (USD) para Real (BRL) em tempo real, fornecendo recursos de busca, filtragem por categorias, ordenação por preço/relevância, paginação dinâmica, página de detalhes do produto, produtos relacionados e carrinho de compras com persistência no localStorage.

## Tecnologias Utilizadas
- React 18/19
- Vite
- React Router DOM v6 (Navegação SPA)
- Context API (Gerenciamento do estado global do carrinho)
- CSS3 (Layout responsivo com CSS Grid e Flexbox)
- DummyJSON API (https://dummyjson.com/products)

## Como rodar o projeto localmente

1. Clone o repositório:
   git clone https://github.com/zRafs/ecommerce2

2. Acesse a pasta do projeto:
   cd ecommerce2

3. Instale as dependências:
   npm install

4. Inicie o servidor de desenvolvimento:
   npm run dev

5. Abra o navegador no endereço indicado pelo terminal (por padrão: http://localhost:5173).
